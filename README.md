# Persona — local prompt studio

React-застосунок для створення персонажів і рольових промптів. Графітова темна тема зі змінними акцентами, EN/UA (англійська за замовчуванням). Генерація відбувається за локальним шаблоном: API-ключі та підключення до ШІ не потрібні.

## Запуск

Потрібен Node.js 20.19+ або 22.12+.

```sh
npm install
npm run dev
```

Відкрийте адресу, яку надрукує Vite (зазвичай http://127.0.0.1:5173).
Інтернет потрібен лише для початкового встановлення залежностей. Застосунок не використовує зовнішні шрифти, CDN, аналітику чи ШІ-сервіси.

Для зібраної офлайн-версії:

```sh
npm run build
npm start
```

Адреса: http://127.0.0.1:4173. Сервер доступний лише на цьому комп’ютері. Зупинити: Ctrl+C. Не відкривайте `dist/index.html` подвійним кліком: для роботи з JSON-файлами потрібен локальний Node-сервер.

## Як користуватися

1. Почніть із порожнього шаблону або оберіть пресет.
2. Налаштуйте особистість, стиль спілкування, цілі, світ і межі у чотирьох вкладках. У кожному списку є «Вписати власне…» для довільного текстового значення; ці значення також можна вказувати безпосередньо у JSON. Риси особистості мають шкалу 1–10. Раніше збережені числові значення не перераховуються автоматично. У першій вкладці розгорніть «Велику п’ятірку» для додаткових рис.
3. На сторінці «Профілі користувача» створіть новий профіль із порожнього шаблону. Заповніть ім’я, роль, контекст, побажання, межі та інвентар, оберіть символ або емодзі для аватара. У розділі «Стиль спілкування / команд» (`speakingStyle`) опишіть бажану манеру звертання до вас: тон, довжину вказівок, форму звертання та інші побажання. Збережіть профіль окремим JSON-файлом.
4. Натисніть «Зробити активним» на потрібному профілі або оберіть його у списку активного профілю в конструкторі. У промпт додається збережений активний профіль; відкриття іншого профілю на редагування не змінює активний вибір. Перший збережений профіль стає активним автоматично. В останній вкладці конструктора можна вимкнути додавання профілю.
5. Введіть назву пресету. «Зберегти пресет» створює JSON-файл; «Оновити пресет» змінює обраний файл. Кнопка з двома аркушами поруч з оновленням зберігає окрему копію.
6. Оберіть мову промпту і натисніть «Згенерувати промпт». Скопіюйте текст або завантажте `.txt`.
7. У бібліотеці можна імпортувати, експортувати та видаляти JSON-пресети. Видалення з підтвердженням видаляє справжній локальний файл.

Перемикач EN/UA змінює мову інтерфейсу, варіантів та майбутнього промпту. Початкові пресети містять готові англійські та українські тексти. Мову промпту також можна вибрати окремо внизу конструктора. Власний текст не перекладається автоматично: офлайн-генератор зберігає його мовою оригіналу. Інструкції промпту та значення списків формуються обраною мовою.

## Локальні файли

```text
data/
  blank.json             # початковий порожній шаблон
  blank-profile.json     # окремий порожній шаблон профілю
  workspace.json         # ідентифікатор активного профілю
  profiles/
    <назва>.json          # окремі профілі з аватарами та інвентарем
  profile.json           # старий файл, якщо існував: резервна копія після міграції
  presets/
    archmage.json        # Прибульці · The Archmage
    companion.json       # The curious companion
    coach.json           # A little momentum
    <назва>.json          # ваші нові пресети
```

Файли можна редагувати у текстовому редакторі, поки застосунок закритий, а потім оновити сторінку. Назви параметрів та ідентифікатори варіантів описані у `src/schema.js`. Порожнє текстове значення — `""`; риси — цілі числа від 1 до 10. `version` має бути `1`. Необов’язковий об’єкт `translations` містить варіанти текстових полів у `en` та `uk`; змінений власноруч текст має пріоритет над готовими перекладами. Імена файлів можуть містити українські літери, цифри, пробіли, крапки, дефіси й підкреслення. Невалідні пресети не завантажуються; застосунок показує їхні назви. Порожній шаблон відокремлено від бібліотеки, і його не можна видалити через інтерфейс.

У localStorage зберігаються чернетка персонажа, обраний пресет, мови та акцентний колір. Збережені пресети та профілі лежать саме у JSON-файлах. Активний профіль зберігається у `data/workspace.json`. Під час першого запуску оновленої версії непорожній старий `data/profile.json` переноситься в окремий профіль без видалення оригіналу. Міграція виконується один раз. Для початку з оновленого `blank.json` створіть нового персонажа через бібліотеку. Резервна копія: скопіюйте папку `data/`.

## Профілі та вигляд

У бібліотеці профілів можна створювати, оновлювати, копіювати, імпортувати, експортувати та видаляти окремі профілі. Назва обов’язкова для збереження. Вона визначає ім’я нового JSON-файлу: наприклад, «Мій профіль» → `мій-профіль.json`. Для пресетів діє таке саме правило. Пробіли й небезпечні символи замінюються дефісами, українські літери зберігаються. Якщо назва зайнята, додається `-2`, `-3` тощо без перезаписування. Для назви лише з емодзі використовується `profile.json` або `preset.json`. Звичайне оновлення зберігає чинне ім’я файлу, навіть якщо змінити відображувану назву. Старі UUID-файли продовжують працювати. Аватар зберігається у полі `avatar` як короткий символ або емодзі (до 16 UTF-16 одиниць). Порожній шаблон `data/blank-profile.json` завжди залишається окремим. Для нового профілю він завантажується під час відкриття застосунку.

Незбережені правки не підміняють активний профіль у промпті. Видалення активного профілю скидає активний вибір; інший профіль можна обрати вручну. Опція «Без активного профілю» вимикає профіль до наступного явного вибору. У JSON-профілі `version` має бути `1`, `name` — непорожній рядок до 100 символів; поля інвентарю — `name` та `description`.

Кнопка з палітрою у верхній панелі відкриває налаштування вигляду: ірис, льодовик, бурштин, троянда, шавлія або будь-який власний колір. Тло лишається нейтральним, змінюються акценти, активні стани та основні кнопки. Вибір зберігається в цьому браузері. Для темних власних кольорів текст кнопок автоматично стає світлим.

## Перевірка

```sh
npm test
npm run build
```

Тести перевіряють кастомні значення всіх списків, шкалу 1–10, Speaking style, читабельні імена та колізії файлів, мову промпту, включення профілю та інвентарю, валідацію, файловий CRUD, оновлення шаблону, незалежні профілі та інвентарі, міграцію старого файлу, збереження активного профілю після перезапуску, видалення та блокування запитів зі сторонніх сайтів.

Архімаг — вигаданий владний наставник, який використовує добровільні квести. Генератор зберігає свободу користувача, межі та можливість поставити гру на паузу; налаштування характеру не є психологічною діагностикою або лікуванням.
